# 滑动窗口策略（有符号库存网格）

分支：`strategy/sliding-window`  
对照：`docs/统计套利与配对交易.md` §8.1  
本分支从 `main` 的分段网格基线分出，把意图层改成「相对窗口中枢的有符号 STEP」，执行层（先挂后吃、单边处理）尽量复用。

---

## 目标形态

同一币、两所 L / R。成交带上的 STEP 是有符号整数，例如 `0→-1`、`-6→-5`、`1→2`。

| 配置 | 含义 |
|---|---|
| 每格代币数量 | STEP 每变 1，两所各开/平这么多 |
| 最大步长 N | `STEP` 夹在 `[-N, +N]`，到顶不再加仓 |
| 滑动窗口样本数 M | 最近 M 个价差样本估中枢 \(\mu\) |
| （隐含）格距 \(\Delta\) | 固定 bps；或由费用地板推出 |

\[
\text{target step} = \mathrm{clamp}\left(\mathrm{round}\frac{s_t - \mu}{\Delta}, -N, +N\right)
\]

- `STEP=0`：相对 \(\mu\) 中性，不是「没机会」
- 变大 → `L_SHORT_R_LONG`（L 相对中枢变贵）
- 变小 → `L_LONG_R_SHORT`（L 相对中枢变便宜）
- 每拍最多调 1 格；过零等于反向开一组新对锁仓

天然基差吃进 \(\mu\)：中枢附近即使 raw 长期非 0 也不持仓。

---

## 和 main 格子的差别

| | main `GridEngine` | 本分支 |
|---|---|---|
| 坐标 | 0…max_segments | -N…+N |
| 方向 | 有仓锁死 buy/sell | 过零即反手 |
| 第一格 | 绝对 T1 | 离开 \(\mu\) 一个 \(\Delta\) |
| 减仓 | 跌破 T0 / T(n−1) 滞后 | 往 \(\mu\) 收回就减（实现时应补滞后，避免贴线磨） |
| 时间 | 100ms 环 + persistence | 窗口按样本滑动；建议固定 hop 采样 |

---

## 实现要点（尚未改代码）

1. 价差 \(s\) 用可执行方向或两所 mid 差，样本丢掉陈旧/锁定盘。
2. 有仓时冻结 \(\mu\) 或放慢更新，避免中枢跟着持仓价差走、永远平不掉。
3. 必须加滞后或 persistence，否则会在 ±1 格振荡（截图 `-6↔-5`）。
4. \(\Delta\) 钉在该所对往返费之上，不要用窗口 range/n 当步长。
5. 意图仍走 `plan_hedge` / sidecar；不要把库存跟踪写进交易所适配器。
