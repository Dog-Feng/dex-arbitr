# 滑动窗口策略

分支：`strategy/sliding-window`。意图层换窗口 STEP；交易所适配器热路径不改。成交均价回填（sidecar 不再把滑点保护限价当成 `avg_price`）已修，见 [本系统套利流程.md](本系统套利流程.md) §6。

| 阶段 | 开发设计 | 做什么 |
|---|---|---|
| 1 | [追 STEP](滑动窗口-阶段1-追STEP.md) | 1Hz 窗口算 μ → 偏离站住 → 有符号 STEP ±1 → **双腿市价**（跟 `plan.style`，不看 yaml `order.style`） |
| 2 | [对称挂限价](滑动窗口-阶段2-对称挂限价.md) | 同一套 μ/STEP；定格距；**两侧邻档各一单**；先挂后吃。**未实现** |

先做阶段 1，再接阶段 2。两阶段不要共用一种 `order.style`。

配置：`pairs.defaults.target_bp`（扣完费+点差后的目标净利，bp）运行时反推 Δ；`grid.step_hysteresis` 代码缺省 0.25，当前 yaml `"0"`。字段见 [配置参考.md](配置参考.md)。

各所另采一条**买卖点差中枢**（与 \(\mu\) 同一套窗口长度，live、不冻）。满窗后 \(C=(\mu_{c,A}+\mu_{c,B})/2\) 折进 Δ：

\[
\Delta=\max\bigl((\text{目标\%}+F+C)/(1-2h),\; F+C\bigr)
\]

空仓未满点差窗不开；有仓未满暂用 \(C=0\)。滑点 / 资金费 / nat 不加。见 [滑动窗口-阶段1-追STEP.md](滑动窗口-阶段1-追STEP.md) §3.4。
