# 滑动窗口 · 阶段 2 开发设计：对称挂限价

依赖：阶段 1 已落地（窗口、\(\mu\)、有符号 STEP、`base_qty`、±N）。  
规格对照：[`滑动窗口-阶段1-追STEP.md`](滑动窗口-阶段1-追STEP.md)

本阶段在 **同一套中枢和库存** 上，把「撞线再市价」改成「邻档限价先挂着，区间来成交」。  
锁定：**取法 A 定格距**；**中枢两侧各一单（邻档）**，不铺满 ±N。  
执行用现有 **先挂后吃**：第一腿限价，成交后第二腿市价对冲。Lighter sidecar 必须能解析账户/精度、订成交频道（见 4.5），否则面板会显示邻档而 DEX 上没有单。

阶段 1 必须先跑通。两阶段不要共用一个 `order.style`。

---

## 1. 目标与非目标

**目标**

空仓时在 \(\mu\pm\Delta\) 各挂一档第一腿限价。价差打到哪边哪边成，STEP ±1，再把邻档挪到「下一格加仓 + 往回减仓」。用 maker 吃格距，插针打不穿挂单价就不成交。

**非目标**

- 按 Δ 铺满两侧全部档  
- 用窗口高低点等分 Δ  
- 一笔成交跳多格  
- 替换阶段 1 的窗口算法  
- 无对冲的裸挂单

## 2. 与阶段 1 的关系

| | 阶段 1 | 阶段 2 |
|---|---|---|
| 中枢 | 1Hz × 10000，有仓冻 μ | 相同；多 \(\mu_{\text{quote}}\) 改价阈值 |
| STEP | 有符号，±1，过零经 0 | 相同，由 **成交** 推进，不是由 persistence 发市价 |
| Δ | 定格距 | 相同 |
| 何时下单 | 偏离站住 → 双腿市价 | 满窗即挂邻档；成交后挪挂 |
| 过滤插针 | 1 秒 5/7 次达标 | 挂单价离现价约 1Δ |
| 开关 | `symmetric_limit=false` | `true`；关回去立刻恢复阶段 1 开仓条件 |
| `order.style` | 发单强制 `market_taker`（不看 yaml） | `limit_then_market` |

阶段 1 的 `persistence_min_hits` 在第一腿限价路径上 **不当扳机**。关掉对称挂单后，开仓重新走持续性 + 双市价，不沿用 F=0 / 离格线够远。  
**邻档第一腿不按 `limit_timeout_ms` 到期转市价**（见 4.4）。第二腿失败立刻市价平第一腿（等该单推送 `ioc_fill_wait_ms` 再查一次，最多 3 次），不做激进限价 IOC。

## 3. 总流程

两条环并行：1Hz 入窗（与阶段 1 相同）+ 100ms 盯挂单/改价。

```mermaid
flowchart TD
  START[process_pair] --> INFLIGHT{本档第一腿已挂<br/>或第二腿对冲中?}
  INFLIGHT -->|对冲中| HEDGE[只盯 hedging<br/>禁止对面档成交]
  INFLIGHT -->|第一腿挂着| WATCH[watch_pending:<br/>成交? 事件撤单?]
  WATCH -->|成交| FILL[对冲第二腿<br/>撤对面邻档<br/>STEP±1 冻/解冻 μ]
  FILL --> PLACE[按新 STEP 挂新邻档]
  WATCH -->|事件撤单| CXL[撤第一腿<br/>本拍可重挂]
  INFLIGHT -->|空闲| WIN[1Hz 入窗 / 更新 μ_live]
  WIN --> FULL{满 10000?}
  FULL -->|否| IDLE[不挂]
  FULL -->|是| QUOTE[算邻档两价<br/>空仓跟 μ_quote 阈值改价]
  QUOTE --> REST{两笔邻档都在?}
  REST -->|缺| POST[先挂后吃: 只挂第一腿]
  REST -->|都在且 μ 未偏够| KEEP[不改价]
  REST -->|μ 偏 ≥ 0.2Δ 且空仓| REPLACE[撤 2 笔按新 μ 重挂]
```

同一时刻每个 slot **最多两个第一腿**（正邻档、负邻档）。任一进入「已成/对冲」必须立刻撤另一档。

## 4. 关键步骤说明

### 4.1 中枢（在阶段 1 上多「挂单价」）

入窗、\(\mu_{\text{live}}\)、有仓冻 μ：与阶段 1 第 3.2–3.3 节完全相同。

空仓时拆两个 μ：

| 量 | 更新 |
|---|---|
| \(\mu_{\text{live}}\) | 每秒有样本就更新 |
| \(\mu_{\text{quote}}\) | 仅当 \(\lvert\mu_{\text{live}}-\mu_{\text{quote}}\rvert\ge 0.2\Delta\) 才换成 live，并撤邻档重挂 |

不要每秒改价，也不要每 5 分钟整表跳一次（邻档会被中枢撞成）。

有仓：\(\mu_{\text{quote}}=\mu_{\text{frozen}}\)，挂单价钉死，直到 STEP 回 0。窗口照样更新 live。

### 4.2 邻档定义（相对当前 k）

取法 A：格线在 \(\mu_{\text{quote}}+m\Delta\)，\(m=\pm 1,\ldots,\pm N\)。只挂 **当前 k 的外侧加一格** 和 **内侧减一格**。

**k=0**

| 档 | 价差轴 | 第一腿方向（空贵） |
|---|---|---|
| 正邻 | \(\mu+\Delta\) | 卖 L（随后买 R） |
| 负邻 | \(\mu-\Delta\) | 买 L（随后卖 R） |

**k=+1**（刚在正边成交）

| 档 | 价差轴 | 作用 |
|---|---|---|
| 加 | \(\mu+2\Delta\) | 再空 L 多 R |
| 减 | \(\mu\)（或 \(\mu+h\Delta\) 滞后） | 平回 0 |

**k=+N**：只挂减仓，不挂 \(\mu+(N+1)\Delta\)。  
负仓镜像。过零必须先成减仓到 0，再恢复 ±Δ 两笔，禁止一档里反手。

不铺满：μ 一漂或插针扫过会连成多格，和 ±1 库存拧着，撤改也扛不住。

### 4.3 价差轴 → 某所限价

格线不是单所价格。例：正档要锁 \(s\approx\mu+\Delta\)，空 L 多 R。

1. 用 **对手所当时盘口** 反推本所限价，使成交后可执行价差尽量等于目标格线。买价必须 ≤ 本所 bid−n tick、卖价 ≥ 本所 ask+n tick（n=`maker_inside_ticks`，至少 1），否则本档本拍不挂。  
2. 第一腿挂在 **「自己 maker + 对面 taker + 对面点差中枢」更便宜的所**（`first_limit_venue_all_in`；缺中枢时只比 maker+taker）。限价所点差不进成本。  
   一格开平 \(F=2\times(\mathrm{maker}_{挂}+\mathrm{taker}_{市})\)，\(C=\) 市价所点差中枢；\(\Delta=\mathrm{target\%}+F+C\)（再除 \(1-2h\)）。**F=0 不挂邻档**（面板「费率未加载」）。yaml 写成 `"0"` 也算 F=0（免费档会踩到）。**只拦阶段 2**；阶段 1 仍用四腿 taker 算 Δ，F=0 照样双市价。  
3. 对手盘口跳一下**不**撤重挂。空仓 \(\lvert\mu_{\text{live}}-\mu_{\text{quote}}\rvert\ge 0.2\Delta\) 才两档都撤、按新中枢重挂。  
4. 第二腿 **等第一腿成交后市价**，与现网 `limit_then_market` 相同。

挂着期间可执行边消失（点差过宽、盘口没了）→ 撤第一腿，不要用过期价等到成交。完整撤单条件见 4.4。

### 4.4 邻档撤单：事件触发，不按秒超时

邻档挂在 \(\mu\pm\Delta\)，等价差自己撞上来。现网 `limit_timeout_ms`（默认 2s）是阶段 1「已经决定成交、挂上去等几秒」的追逐超时；套在邻档上会不停撤重挂，maker 格距没了。

**邻档一直挂着，直到下面某一条发生才撤**，不是墙钟到点：

| 触发 | 动作 |
|---|---|
| 对面邻档先成 | **立刻撤**本档，防插针双边都成 |
| 可执行边没了（盘口没了、点差过宽） | 撤，本拍可重挂。盘口**短暂**过期（约 3s）**不撤** |
| 空仓 \(\lvert\mu_{\text{live}}-\mu_{\text{quote}}\rvert\ge 0.2\Delta\) | 两档都撤，按新中枢重挂 |
| 价差朝格线靠、反推限价交叉 | **不撤**（让第一腿成交；「离格线够远」只挡新挂） |
| 对手所盘口把反推限价挪过 1 tick | **不撤**（避免 BTC 每跳都撤重挂） |
| 点差窗未满 | **不撤**已挂单（空仓未满窗本来就不会新挂） |
| 有 Foreign / 裸腿 | **不挂**开仓档和减仓档（面板「单边敞口」）。Foreign 仓**不自动补对冲** |
| 邻档双边都成（输掉竞态） | 紧急平多出来的那腿后 **冷却 3 秒** 再挂 |
| 费率 F=0 | **仅阶段 2 不挂**（面板「费率未加载」）。yaml `"0"` 与没读到一样。阶段 1 不走这条 |
| 反推限价离本所 bid/ask 不足 `maker_inside_ticks`（至少 1 tick） | **这一档本拍不挂** |
| 停止套利 | 撤邻档；已发出的单听到成交后**不再市价对冲 / 紧急平** |
| STEP 变了 / 强制平仓 | 撤光邻档 |
| 执行 task 挂死 | 现有硬看门狗（分钟级）清状态、查孤儿单 |

**不要**「邻档超时 → 改市价吃掉」。那会变成阶段 1 追价，插针也会被吃进。

现有 `limit_timeout_ms` / `limit_retry_count` 只留给：**非邻档追逐型限价**。市价、IOC、撤单确认走 `order.ioc_fill_wait_ms`（默认 1000，可改 2000/3000）：等该单 WS，没有再 REST 查一次该单。邻档本身：`adjacent_timeout_ms=0` 不按时间撤，不要沿用 2000ms。

流程图里的「盯挂单」= 成交 / 上表事件，不是 2 秒转市价。

### 4.5 成交与对冲

认成交：**该所、该 `order_id` 的私有 WS**，不用账户缓存仓位差。邻档挂着一直听，直到事件撤或成交（`adjacent_timeout_ms=0`）。市价 / IOC / **撤单之后**：等该单 WS 最多 `ioc_fill_wait_ms` → 没有再 REST 查一次该单 → 仍没量当失败。

1. 第一腿成交（含部分：立刻市价对冲该增量，余量继续挂；整格 `base_qty` 满了才算这一档成、推进 STEP）。  
2. **立刻撤对面邻档**（防插针双边都成）。  
3. 市价对冲第二腿；失败立刻市价平第一腿（`ioc_fill_wait_ms` 推送 + 查一次，最多 3 次），禁止裸腿挂着继续开。  
4. STEP ±1；`0→±1` 冻 μ；`±1→0` 解冻。  
5. 按新 k 挂新的加档、减档（缺的才挂，已在的对齐价格）。

对冲未完成前，该 slot 视为 inflight，**不得**让另一档成交（应对面已撤）。回滚 3 次仍未确认 → `NAKED_FIRST_LEG`。启动时已有的 Foreign 仓只告警，不自动补。

**面板「邻档 n/2」是内存 pending，不是 DEX 查单。** pending 在 spawn 发单**之前**就写入；place 失败（精度未知、client id 撞号）也会显示邻档，DEX 上没有单。成功应看到日志 `limit_market: first leg posted`，随后 DEX 出现对应限价。

Lighter sidecar（现网已改，缺了会静默挂不出去 / 认不到成交）：

| 点 | 要求 |
|---|---|
| 私有 WS | 订 `account_all_orders` **和** `account_all_trades`。orders 按市场 id 分组是 **map**（`{"1":[Order]}`），不是数组；成交量常在 trades（`ask_client_id` / `size`） |
| 查单 | `initial − remaining`；活跃列表没有再查 inactive（IOC 成交后不在活跃列表） |
| `rawList` | 只展开「市场 id → 订单/成交数组」。**不要**递归拆账户快照、`orderBookDetails`。拆开会：`lighter market N decimals unknown`（挂单失败）、`account snapshot unavailable`（余额拉不到） |
| `client_order_id` | 整数且 ≤ \(2^{48}-1\)（`281474976710655`）。现网 `ms*100 + n%100`；不能用同一毫秒时间戳，也不能 `ms*1000+seq`（超上限被拒） |

### 4.6 μ 变动对邻档的影响

空仓、μ 慢漂但不足 0.2Δ：两笔挂单价不动。  
空仓、μ 从 0 漂到 0.2Δ：撤 ±Δ 旧单，按新中枢重挂。此时旧正档可能已贴近新中枢，必须先撤再挂，避免「中枢自己撞上挂单」误开。  
有仓冻 μ：加/减线不跟 live，这是减仓还能平回开仓中枢的前提。

铺满两侧时每次定值要动 2N 笔，且容易一次穿多档——本阶段明确不做。

### 4.7 一格收益（与阶段 1 相同，成交方式不同）

\(\mu=0\)，\(\Delta=0.02\)（报价差或 % 与配置一致），数量 \(q\)：

1. 正档在 +0.02 成交：空 L / 多 R 各 \(q\)  
2. 减档在 0 成交：平掉  
3. 毛利 \(\approx 0.02q\) −（第一腿 maker + 第二腿 taker）× 开平两次  

A=100、B=99 若相对 μ 真偏离，逻辑同阶段 1；差别是单子事先挂在 \(\mu+\Delta\)，不是偏离后再两腿市价去追。

## 5. 状态机（每 slot）

```
IdleEmpty ──满窗──► RestingTwo          两笔邻档挂着
RestingTwo ──正档第一腿成──► HedgingPlus   撤负档，对冲中
HedgingPlus ──第二腿成──► RestingAtK     k=+1，挂 +2 与回 0
RestingAtK ──减档成──► HedgingFlat      对冲平仓
HedgingFlat ──成──► RestingTwo 或 Idle   回 0 解冻 μ，再挂 ±Δ
RestingTwo ──μ 偏 0.2Δ──► ReplaceTwo    撤重挂，仍空仓
任一 Resting ──事件撤单──► Cancel 再回到对应 Resting/Idle
```

`k=-1` 对称。强制平仓：撤所有邻档，市价清 \(\lvert k\rvert\) 格（阶段 1 已有路径）。

## 7. 落地顺序

1. 邻档纯函数单测：k=0/±1/±N 的两档价差与方向  
2. 双 pending 或等价结构 + 撤对面  
3. 接 `watch_pending`：成交 → 对冲 → 挪档；事件撤单（边没了 / 0.2Δ / 对面先成），**不**按 2s 转市价，**不**因 1 tick 改价撤  
4. \(\mu_{\text{quote}}\) 阈值重挂  
5. paper：空仓两单、正成负撤、回到 0 恢复 ±Δ  
6. 强制平仓撤光挂单

## 8. 验收

- 满窗空仓：恰好两笔第一腿，价差轴约 \(\mu\pm\Delta\)  
- 未满窗：零挂单  
- 正档成交：负档已撤；STEP=+1；随后只有 +2 加仓与回 0 减仓  
- 减到 0：解冻；重新 ±Δ  
- live 漂不足 0.2Δ：不改价  
- 有仓灌偏 live：减仓线仍按冻结 μ  
- 第一腿成、第二腿失败：紧急对冲，无裸腿  
- 插针同时碰到两档：只承认先成的一档  
- 邻档挂着超过 2s 仍未成交：不得改市价；仅上表事件才撤  
- 不出现 2N 张网格单  
- 面板「邻档 n/2」且日志 `first leg posted`：DEX 上能看到对应限价；不得长期只有邻档状态、DEX 空簿  
- 不得出现 `lighter market N decimals unknown` / `account snapshot unavailable`（`rawList` 回归）
- F=0：阶段 2 面板「费率未加载」、零邻档；关掉 `symmetric_limit` 后阶段 1 仍可开仓
- 点停止：已发出的邻档成交后不再市价对冲 / 紧急平

## 9. 未落地：F=0 + 剧烈波动

两所都是免费档时 F 真为 0，Δ 只剩 `target_bp`+C，对称挂单在跳空里容易两边都成。加大 `target_bp` 过不了 F=0 闸，也挡不住扫穿 \(2\Delta\)。下面三条**还没写进代码**：

1. **格距用短窗波动垫底**：经济 Δ 照旧（F 可以为 0）。另取最近几秒 μ 高低差 \(R\)，\(\Delta_{\mathrm{eff}}=\max(\Delta,\alpha R)\)，让两侧间距离开短窗振幅。
2. **波动大时只减不加**：\(R\ge 2\Delta\) 时有仓只挂减仓（仍在 μ），不挂下一格开仓。
3. **竞态后等落下再挂**：紧急平保留。不要 3 秒一到就贴 μ 挂减仓；等到 \(R<2\Delta\) 且两所仓位核对已平，再挂空仓双侧。

F=0 闸届时应放开（免费档合法）。双边都成在撤单延迟里无法 100% 消灭。
