# 统计套利 / 配对交易（Stat Arb, Pairs）

本文整理业界「第六种」价差思路：**统计套利 / 配对交易**。它不是本仓库当前的主路径（当前是同一币种跨所分段网格），而是相对价值：两腿（或一篮子）在统计上应一起走，价差偏离历史关系后做多便宜腿、做空贵的腿，赌关系恢复。关系可以永久坏掉，所以每一种方案的核心都是「用什么定义关系、怎么开平、坏了怎么认赔」。

本仓库基线仍是空间套利（`main`）。后续两条试验分支：

- `strategy/sliding-window`：滑动窗口 + 有符号固定步长库存网格
- `strategy/z-score`：把偏离按波动标准化后再开平

---

## 1. 和真套利差在哪

| | 真套利（本仓库现状） | 统计套利 / 配对 |
|---|---|---|
| 两腿 | 同一合约、不同所 | 不同标的，或同一标的相对一条估出来的中枢 |
| 收敛依据 | 一价定律（执行风险为主） | 历史关系 / 因子中性，**可以不回归** |
| 空仓时 | 可执行 raw 够宽才开 | 残差够偏才开 |
| 主要残差 | 延迟、单边、滑点 | 结构漂移、共同跳水、选对偏差 |

加密里 stETH/ETH、wBTC/BTC 介于两者之间：正常时像基差，脱锚时是信用事件。

---

## 2. 任何一套都由三层拼起来

名字往往只说了其中一块：

1. **关系模型**：两腿怎么对冲（1:1、回归 β、协整向量、动态 β、因子残差）
2. **信号**：什么叫「够偏」（距离、z-score、OU 阈值、分位数、模型预测）
3. **仓位与离场**：一次打满、网格加仓、半衰期超时、硬止损、结构破坏就停

下面按业界可落地的完整套路列方案，而不是只列指标名。

---

## 3. 方案目录

### 方案 A：距离法配对（Distance / SSD）

最老的「选对 + 交易」流水线（Gatev 等人股票 pairs 的原型）。

- 价格标准化成累计收益或归一化价格。
- 历史窗口算平方偏离和（SSD），偏离小 = 走得齐。
- 全市场或同板块选出 SSD 最小的 N 对。
- 交易期：价差再偏离过阈值就开，回归均值就平。
- 对冲通常是**美元中性**（两边名义相等），不管 β。

适合：标的多、先筛「谁跟谁配」、不想先做协整检验。  
弱点：过去走得齐 ≠ 以后还齐；名义中性时残差 β 可能很大。

### 方案 B：协整配对（Cointegration）

统计上最「正统」的 pairs：价差本身平稳，不是两条价格碰巧相关。

- **Engle–Granger**：\(P_A = \alpha + \beta P_B + \varepsilon\)，再测 \(\varepsilon\) 是否平稳。
- **Johansen**：多资产、多协整关系（一篮子 vs 一篮子）。
- 开仓看残差 \(\varepsilon\)（或 log 价差），对冲比是 **β（协整向量）**，不是 1:1。

适合：包装资产 vs 原生、LST vs ETH、同一指数的不同合约。  
弱点：样本内协整、样本外经常失效。必须有**协整破裂规则**（残差变单位根、半衰期突然变长 → 停做这对）。

### 方案 C：β / 因子中性配对（Beta-neutral）

不要求协整，只对冲共同因子，做 idiosyncrasy。

- \(r_A = \alpha + \beta r_B + \varepsilon\)（或对 BTC、对板块指数）。
- 交易 \(\varepsilon\) 的累计或 z-score。
- 做多 A 1 单位、做空 B 的 \(\beta\) 单位 → **β 中性**，不是美元中性。

和 B 的差别：B 做价格水平的长期均衡；C 做收益因子暴露。短期更稳，长期残差可以有漂移（α）。  
加密里大量「BTC 中性山寨 pairs」其实是 C。

### 方案 D：OU 过程 + 最优阈值

把价差当成 Ornstein–Uhlenbeck：\(dS = \kappa(\mu - S)dt + \sigma dW\)。

- \(\kappa\) → 半衰期 \(\ln 2 / \kappa\)
- 入场：\(\mu \pm k\sigma_{\text{eq}}\)（\(k\) 常用 1.5～2.5）
- 离场：回到 \(\mu\)，或反向阈值
- 持有超过 2～3 个半衰期仍不回归 → 时间止损（当结构坏了）

更讲究的用 Bertram 一类结果，按 \(\kappa,\sigma\) 算使夏普最大的开平阈值。  
弱点：\(\kappa\) 估不稳时最优阈值是假的；加密价差常有跳变，纯扩散 OU 低估尾部。

### 方案 E：Kalman / 动态对冲比

β 不是常数。Kalman（或滚动回归、指数加权）让对冲比跟着走。

- 状态：\(\beta_t\) 慢变
- 观测：\(P_{A,t} = \beta_t P_{B,t} + \varepsilon_t\)
- 交易滤波后的 \(\varepsilon_t\)

适合：ETH/BTC 这种比值本身在变、但短期仍回归的对。  
风险：滤得太快，趋势被吸进 β、信号消失；滤得太慢，结构变了还在用旧 β。

### 方案 F：因子残差 / PCA 统计套利

大型股票量化里说的 stat arb，多半不是两只股票配对：

1. PCA / 基本面 / 行业因子解释横截面收益
2. 每只股票留下特质残差
3. 残差过高则空、过低则多，组合整体因子中性

Avellaneda–Lee 是公开文献里常被引用的版本。  
加密对应：因子用 BTC、ETH、板块、funding、市值；做的是相对篮子，不是固定 2 条腿。这是工业化 stat arb，不是零售 pairs bot。

### 方案 G：一腿对一篮子（1 vs N）

A 对冲的不是单个 B，而是一篮子（某 L2 vs 一篮子 L2；某永续 vs 合成）。  
对冲比用多元回归或约束最小二乘（美元中性 + β 中性一起加约束）。比 2 资产稳，腿多、执行和手续费变主矛盾。

### 方案 H：分位数 / 极值（不假设正态）

z-score 默认残差近似正态。实务常用：

- 滚动分位数：跌破 10% 分位做多价差、升破 90% 做空
- MAD / 分位数波动代替标准差（抗插针）
- 进场用极值，离场用中位数，减少阈值附近来回磨

加密盘口噪声大时，往往比 2σ 更好用。

### 方案 I：Copula / 非线性相关

线性相关在两边一起暴涨暴跌时会失效。Copula 描述分位数依赖（尾部同跌）。  
学术多、生产少：估不稳、样本外尾部依赖会变。除非专门做压力期相对价值，否则优先 B/C/E。

### 方案 J：预测残差（不是无条件反向）

经典 stat arb 是无条件均值回归（偏了就赌回来）。  
进阶：用短期特征预测残差下一步（盘口不平衡、funding、链上、波动率状态），只有模型认为会回归才开；偏了但模型认为会继续发散则不做或反手做动量。  
这已是相对价值 + 预测，中型 crypto 量化的常见形态。

## 4. 同一模型也能长成四种交易系统

关系模型选定之后，仓位方案仍可独立选：

| 交易系统 | 行为 |
|---|---|
| 单次阈值 | 破 2σ 一次开满，回均值全平；阈值附近容易来回磨 |
| 分段网格 | 价差每宽一档加一格，回落滞后减 |
| OU 最优带 | 开平阈值由 \(\kappa,\sigma\) 算出，格子步长不再拍脑袋 |
| 时间/结构止损 | 超半衰期、协整破裂、β 跳变 → 强制平 |

网格是执行层，stat arb 是**信号定义在统计残差上**。两者不互斥。

---

## 5. 加密里常见的品种套法

1. **BTC–ETH 比率**：方案 C 或 E，β 中性；趋势年里比率可以单边走很久，必须有时间止损。
2. **LST / 包装 vs 原生**（stETH–ETH、wBTC–BTC）：接近协整 + 锚定。方案 B + 脱锚硬止损，不要用纯 z-score 死扛。
3. **同板块山寨**：方案 A 筛对 + B/C 交易；死亡率高，要按周重选。
4. **永续 vs 现货**：很多团队叫 pairs，本质是期现/funding，不该放进纯 stat arb 的风控假设。
5. **同币跨所**：这是空间套利，残差应趋向 0（或趋向天然基差）。用 stat arb 的 z-score 直接套，会把「该立刻收敛的东西」做成「等 2σ」，通常更差。要对跨所做「类似 z」的东西，应打在 **扣掉慢中枢之后的 residual** 上，见两条策略分支。

---

## 6. 风控上各方案都会踩的坑

- **选对偏差**：样本内最齐的 20 对，样本外往往最容易一起崩。
- **共同跳水**：相关升到 1 时，美元中性仍大亏；要压尾部因子，不只是历史 σ。
- **残差非平稳**：看起来像回归，其实是缓慢漂移。半衰期监控比 z-score 本身重要。
- **执行不对称**：两腿深度、费率、可否做空差很多时，纸面夏普会消失。
- **杠杆**：残差 σ 小，容易加太多；一次结构破坏就回撤掉一年。

能活下来的组合几乎都是：中性约束（美元 + 因子）+ 半衰期超时 + 结构破裂熔断 + 单对/单因子限额。信号用 A 还是 E 是第二位的。

---

## 7. 怎么选

- 要一条能先跑起来的线：**A 筛对 + 分位数开平 + 时间止损**。
- 有锚定关系（包装、LST）：**B + 脱锚硬止损**。
- 做 BTC 中性山寨：**C 或 E**，组合层面再加 BTC/ETH 因子中性（靠向 F）。
- 标的池子大、要工业化：方向是 **F（因子残差）**，不是把 200 对经典 pairs 堆在一起。
- 已有跨所网格引擎：不要把 BTC–ETH 硬塞进现在的 `raw_spread`；要另开「残差序列 + 对冲比」的意图源，执行层（先挂后吃、单边处理）可以复用。

## 8. 本仓库：同一币跨所时的两种试验

同币跨所不是配对交易，但可以用 stat arb 的**信号层**（窗口中枢、z-score）去替代写死的 T1。两条分支都假设：L 与 R 是同一永续、两所对锁。

### 8.1 滑动窗口 + 固定步长（有符号库存网格）

配置通常是：每格代币数量、最大步长、滑动窗口样本数。

- 窗口估公允中枢 \(\mu\)（均值或中位）
- \(\mathrm{step} = \mathrm{clamp}(\mathrm{round}((s-\mu)/\Delta), -N, +N)\)
- `STEP=0` 是相对中枢中性，不是「没机会」
- 正 STEP：空 L / 多 R；负 STEP：多 L / 空 R；过零即反向
- 每拍最多调 1 格；打到最大步长停止加仓

和当前 `GridEngine`（0…max_segments、方向锁定、绝对 T1）不同：这是 **-N…+N 相对 \(\mu\)** 的库存跟踪。缺滞后时会在格线附近来回成交。

### 8.2 z-score

同一中枢 \(\mu\)，尺子换成波动：

\[
z_t = \frac{s_t - \mu}{\sigma}
\quad\text{或稳健版}\quad
z^{\text{rob}} = \frac{s_t - \mathrm{median}}{c\cdot\mathrm{MAD}}
\]

- 开仓：\(\lvert z \rvert \ge k_{\text{in}}\)；平仓：\(\lvert z \rvert \le k_{\text{out}}\)
- 波动大时自动抬高绝对门槛；波动小时更容易在中枢附近刷
- 跨所手续费是绝对百分比，实务应加地板：\(\lvert s-\mu \rvert \ge \max(c,\, k\sigma)\)

### 8.3 两者对照

| | 滑动窗口固定步长 | z-score |
|---|---|---|
| 一格 | 固定 \(\Delta\)（bps） | 1 个（稳健）σ |
| 适应波动 | 否（剧烈市容易顶满） | 是（σ 被撑大后变钝） |
| 格距 vs 手续费 | \(\Delta\) 可直接钉在费用上 | 必须另加成本地板 |
| 贴线磨 | 安静市按 \(\Delta\) 抖 | σ 缩小时按 \(k\sigma\) 抖 |
| 参数 | 每格数量、最大步长、窗口样本数 | 窗口、\(k_{\text{in}}/k_{\text{out}}\)、是否 MAD |

杂交：\(\mu\) 仍用滑动窗口；第一格用 \(\max(\Delta_{\min}, k\sigma)\)；后面仍按固定 \(\Delta\) 加到最大步长。
